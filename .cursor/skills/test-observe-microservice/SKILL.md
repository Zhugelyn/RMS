# Test Observe Microservice

## Инструкции

1. Прочитай `agents/testing-observability-agent.md`.
2. Определи changed behavior and blast radius.
3. Выбери минимальный достаточный набор unit, integration, contract и e2e tests.
4. Добавь observability requirements: logs, metrics, traces, health checks и alerts.
5. Зафиксируй test gaps явно, если автоматическая проверка невозможна.
