# Learn Microservices Playbook

## Объяснение темы

Используй структуру:

1. Короткий ответ в 2-4 предложения.
2. Практический пример на текущем стеке.
3. Anti-pattern.
4. Как сделать правильно.
5. Маленькое упражнение.

## Roadmap

1. Модульный монолит vs микросервисы.
2. Bounded context и ownership данных.
3. REST/gRPC contracts.
4. RabbitMQ commands и Kafka events.
5. Outbox/inbox и idempotency.
6. Saga/process manager.
7. PostgreSQL per service.
8. MinIO file flows.
9. Kubernetes/Nginx deployment.
10. Security and observability.
